## 📖 About The Repository

This repository contains all 20 mini-projects developed throughout the **[JavaScript Web Projects: 20 Projects to Build Your Portfolio](https://www.udemy.com/course/javascript-web-projects-to-build-your-portfolio-resume/)** course on Udemy.

These projects are built using **pure Vanilla JavaScript, HTML5, and CSS3**—no frameworks or external libraries. This repository serves as a showcase of modern DOM manipulation, asynchronous programming, Web APIs, and more.

---

## 🛠️ Technologies & Concepts Learned

- **Vanilla JavaScript:** DOM Manipulation, Event Listeners, Fetch API & Promises, Async/Await.
- **HTML5 & CSS3:** Flexbox, CSS Grid, Custom Properties (Variables), Responsive Design, Animations, Dark/Light Mode.
- **Web APIs:** Local Storage, Speech Synthesis API, Web Audio API, Canvas API, Picture-in-Picture API.
